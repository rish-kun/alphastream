## 2023-10-25 - [SQLAlchemy Conditional Aggregation]
**Learning:** Multiple aggregate queries over the same dataset (such as separate count queries for different conditions, e.g., bullish/bearish/neutral sentiment) can be combined and executed as a single query using SQLAlchemy's `func.count(case(...))` alongside other aggregations like `func.avg(...)`.
**Action:** Always look to combine sequential queries that compute metrics over the same filtered dataset by using conditional aggregation, retrieving a single result tuple to reduce database round-trips. Note that testing these endpoints using `conftest.py`'s `MockResult` requires ensuring it has a `.first()` method and mocking the response data as a single tuple containing all aggregated values (e.g., `MockResult(data=[(0.35, 10, 5, 15)])`).
